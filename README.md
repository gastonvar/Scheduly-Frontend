# Scheduly Frontend

React SPA for Scheduly. The API is [Scheduly-Backend](https://github.com/gastonvar/Scheduly-Backend).

## Local

```bash
cp .env.example .env
npm install
npm run dev
```

Open `http://localhost:5173` (not `127.0.0.1`). `VITE_API_URL` defaults to `http://localhost:4001`.

Login uses the seeded backend user (see the backend README).
